Your Windows desktop bends as you close the lid.

WinBend captures your live desktop and folds it like a laptop lid coming down: it tilts, bends, blurs and settles, the iPhone Duo fold on the laptop you already own. Press a key, or let it follow the lid through your webcam. Free and open source for Windows 10 and 11.

Download for Windows Source on GitHub

Free and open source (MIT). Installer or a single portable file, no account, no network. Windows 10 2004+ / Windows 11.

How it works

Live desktop

Windows.Graphics.Capture feeds the real screen into a Direct3D 11 renderer, so windows and wallpaper move together. Anti-aliased, 60 fps.

Follow the lid

Opt-in webcam tracking turns camera motion into a lid angle. The fold runs through the last degrees before shut and lifts as you open. Guided calibration fits it to your laptop.

Four styles

Silk, Shade, Frost, and Origami, which creases the desktop into zigzag panels that compress like an accordion. Custom adds panels, perspective, blur, shadow, bend, vignette and sheen sliders with a live preview of your own desktop.

Sleep & wake

Fold finishes as the PC sleeps and the desktop is still folded when the screen returns, then lifts. Optional: let WinBend handle the lid so the fold plays before sleep.

Shortcuts

Ctrl+Alt+B folds or unfolds anywhere. Ctrl+Alt+C toggles lid tracking. Both are changeable with a press-a-key picker.

Private by design

Frames are processed on your PC and dropped immediately. Nothing is recorded, saved or uploaded. The camera light is on whenever tracking is on.

Four ways to fold

Pick one in Settings, or build your own with the Custom sliders. The live preview shows your real desktop while you tune.

Silk

Clean perspective with a soft bend near the hinge and a glossy band that sweeps down as it closes. The default.

Shade

Deep shadow gathers toward the far edge, so the desktop looks like it is sinking into the dark behind the lid.

Frost

The picture blurs as it tilts, like frosted glass coming down, and sharpens again the moment the lid lifts.

Origami

The desktop creases into three zigzag panels that compress like an accordion, each facet lit as its own plane. Set 2 to 8 panels in Custom.

Download

Get it

Run WinBend-Setup-<version>.exe from the latest release: no admin prompt, Start menu entry, optional start at sign-in. Prefer portable? The same release has WinBend-<version>-win64.zip: unzip and run winbend.exe. Either way WinBend lives in the tray and a welcome window opens the first time.

Requirements

Windows 10 version 2004 or later, Windows 11 recommended. Any Direct3D 11 GPU. Microsoft Edge WebView2 Runtime for the settings window (included with Windows 11).

Unsigned, for now

Windows may show “Windows protected your PC” for a new download: choose More info → Run anyway. The source is public and you can build it yourself.

Questions people ask

Is WinBend free?

Yes. Free and open source under the MIT license. No trial, no account, no license key. Donations are welcome but optional.

Is this Bendy for Windows?

WinBend is an independent Windows app inspired by Bendy for macOS and the iPhone Duo fold animation. It renders the same kind of effect, the desktop tilting, bending, blurring and shading as the lid closes, on Windows 10 and 11.

Do I need a hinge angle sensor?

No. Most Windows laptops have none, so WinBend can track the lid through the webcam: as the lid tilts, the camera image shifts, and that becomes a lid angle. A short guided calibration fits it to your laptop. Laptops with a hinge sensor or lid accelerometer can use those directly.

Does it work without a webcam?

Yes. Press Ctrl+Alt+B to fold on any desktop, let the desktop fold when the PC sleeps and unfold when it wakes, or fold automatically when idle.

Which Windows versions?

Windows 10 version 2004 or later and Windows 11, on any PC with a Direct3D 11 GPU. The settings window uses the Edge WebView2 Runtime, included with Windows 11.

Is my screen recorded?

No. Desktop and webcam frames are processed on your PC and dropped immediately. WinBend makes no network connections. The camera light is on whenever webcam tracking is enabled.
